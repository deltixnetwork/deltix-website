# Deltix Network — Website

The official landing site for [deltixllc.com](https://deltixllc.com), served by **GitHub Pages**.

## How to edit (no tools required)

1. Open [index.html](index.html) on github.com and click the ✏️ pencil icon
2. Change the text you want (everything is in this single file — content and styling)
3. Click **Commit changes** — the live site updates automatically within a minute

## Structure

- `index.html` — the entire site (content + styles in one file for easy editing)
- `CNAME` — the custom domain binding (do not delete)
